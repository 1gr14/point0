Собрано финальным ревью фичи 2026-07-31. Всё ниже — аддитивные расширения:
ничего из этого не ломает существующий контракт, и у каждого пункта есть
документированный обход. Rejected-ideas в
[dev/docs/socket.md](../docs/socket.md) сверены — ничто отсюда с ними не
конфликтует.

- **Kick `reason` на клиентской поверхности.** Сегодня `reason` едет в кадрах
  `closed`/`left` (сырой ws-клиент его читает), но типизированный рантайм его не
  всплывает — ни на фасаде, ни в `onDisconnect`/`onLeave`. Обход
  задокументирован (пуш перед киком); поверхность на будущее — поле на фасаде
  (`closeReason?`) + причина в пропсах лайфсайкла. Дизайн согласовать: причина
  шринка мембершипа (space-kick) не имеет очевидного места — `onLeave` при
  шринке не фаерится.
- **Fire-and-forget send без reply-кадра.** Каждый `sendToServer` стоит кадра
  `{t:'reply'}` обратно — для 30–60 Гц курсоров/инпутов это ×2 трафика. Обход:
  батчить на клиенте. Поверхность: опция хендлера/вызова «без ответа» (сервер не
  кадрирует reply, клиент не ждёт).
- **Сигнал «первый вошёл / последний вышел» по комнате.** Для авторитативного
  цикла комнаты (мультиплеер-тик) сегодня нужен свой лидер-элект поверх
  `pointSpaceJoinServerSuccess`/`pointSpaceLeaveServer` + внешний лок. Сигнал
  должен остаться ПРОИЗВОДНЫМ от room-индекса (никакого пер-джойн стейта —
  запрещено Rejected ideas).
- **`sendToClient` вне процесса с `engine.serve()`.** Адаптер регистрирует
  только живой сервер; отдельный воркер-процесс пушить не может (формат
  bus-конвертов внутренний). Обход: воркеры/кроны живут рядом с serve (это
  документированный шейп деплоя, и доки теперь оговаривают ограничение).
  Поверхность на будущее: «издатель без сокет-сервера» поверх бэкплейна.
- **Энумерация комнат / count по комнатам.** «Список активных комнат» не
  выражается (и по доктрине лобби живёт в БД); счётчики по N комнатам — N
  гезеров. По спросу: `rooms()` на кластерном этаже / группировка count.
- **`iterateMessagesFromServer` теряет `room`.** Листенеры получают
  `{ message, room }`, итератор йелдит голый message — спейс-хендлерный консюмер
  не узнаёт, какой комнате пуш адресован. Поверхность: опция/вторая форма йелда.
- **Binary payloads** («Not shipped yet» в публичной доке): транспорт сейчас —
  один JSON-конверт на кадр; бинарь = отдельный формат кадра + схемы. Смежно с
  [socket-transport.md](socket-transport.md).
- **Встроенный rate limiting** («Not shipped yet»): рецепт `onBeforeServerReply`
  работает уже сейчас и задокументирован; встроенный — это опция-кап (msgs/sec
  на соединение) рядом с `maxMessageSize`.
